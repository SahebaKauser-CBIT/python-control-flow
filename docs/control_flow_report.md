# Python Control Flow - Internship Report

## 1. Objective
The objective is to learn conditional statements and loops by writing Python programs.

## 2. Conditional Statements
The if statement executes when a condition is true. The elif statement checks another condition, and else handles the remaining case. The modulo operator (%) helps identify even and odd numbers.

## 3. For Loop and While Loop
A for loop iterates over a sequence or range. This project uses it for multiplication tables and triangle patterns. A while loop repeats while its condition is true. It calculates the sum of natural numbers by adding values from 1 through N.

## 4. Mathematical Operations
The multiplication table multiplies a selected number by integers from 1 to 10. The sum of the first five natural numbers is 1 + 2 + 3 + 4 + 5 = 15. The triangle pattern adds one asterisk on each successive row.

## 5. Testing
Test the number checker with 8, -5, -4 and 0. Test the loop program with different numbers, positive N values and different row counts. Non-positive N and row values are handled with messages.

## 6. Conclusion
This task demonstrates decision-making, loops, arithmetic, input and output in Python. Actual terminal screenshots should be added to docs/screenshots.
