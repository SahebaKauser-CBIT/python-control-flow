# Python Control Flow

## Overview
A beginner Python project demonstrating conditions and loops.

## Requirements
Python 3

## Run the programs
python src/number_checks.py
python src/loop_operations.py

## Concepts learned
- if, elif and else
- for and while loops
- Even and odd number classification
- Multiplication tables
- Sum of natural numbers
- Star pattern generation
